# Appliance Energy Consumption Website

## Overview

This is a small interactive website about appliance energy consumption in Australia. The project was created to demonstrate the use of HTML, CSS, JavaScript, Git and GitHub.

The website has three pages:

* **Home** – General information, an FAQ section and an energy calculator.
* **Televisions** – Information about TV energy consumption and ways to reduce usage.
* **About Us** – Information about the project and the technologies used.

## Interactive Features

The Home page includes an FAQ accordion where users can click on questions to show or hide the answers.

It also includes an energy calculator. Users can enter the appliance power, hours used per day and electricity price. JavaScript then calculates the estimated daily, monthly and yearly energy usage, along with the estimated costs.

The calculator also checks the input values and displays an error message if they are invalid.

## Technologies Used

* **HTML** – Used for the structure and content of the website.
* **CSS** – Used for the layout, colours, spacing and overall design.
* **JavaScript** – Used for the FAQ and energy calculator.
* **Git/GitHub** – Used to track and store the project during development.

No external JavaScript libraries were used.

## Design

The website uses a simple design based around the colours of the provided Power logo. The same navigation, styling and footer are used across all three pages.

The layout also includes some responsive styling so the website can work on smaller screens.

## Generative AI Reflection

I used ChatGPT to help with the website structure, CSS ideas, JavaScript functionality and some debugging.

I tested and adapted the generated code to fit the requirements of the project rather than using it without changes.

Using ChatGPT helped me understand how HTML, CSS and JavaScript work together, especially with JavaScript events, form inputs and updating webpage content.

One limitation I noticed was that AI-generated code does not always work perfectly on the first attempt, so I still had to test the website and make changes myself. It was also important to understand the code rather than just copy it.
